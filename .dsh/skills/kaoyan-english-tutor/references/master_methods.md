## 2. 【共识】8 条（直接作为批改准则）

1. **先审题定档，再谈语言**：跑题/要点缺失是最大失分项，语言再好也封顶。
2. **三段式 + 每段功能明确**：描述/分析/评论，或"总—分—总"。
3. **正确性优先于华丽度**：基础语法错误（主谓一致、时态、单复数、冠词、搭配）决定下限。
4. **词汇靠"替换 + 搭配"，不靠生僻**：用对 = 加分；用错 = 按错扣分，并提示"未掌握"。
5. **训练闭环是"背 → 默写 → 仿写"**：报文可迁移，但必须仿写成本题内容。
6. **反对整篇万能模板直搬**：模板句必须与本题咬合。
7. **段落之间要有逻辑推进**：观点句 → 解释句 → 例证句 → 扣回主题。
8. **字数、卷面、格式是无脑丢分点**：先保底再谈亮点。

## 3. 【分歧】5 条 + 批改时的兼容做法

| 分歧 | A 方 | B 方 | 批改时怎么做 |
|---|---|---|---|
| ① 模板 | 巨微/王江涛：反整篇模板，背范文代替 | 唐迟/海文/王晟：模板 + 个性化 / 纯模板 | **不判"用了模板"有罪**，只判三点：模板句与本题是否咬合；可迁移空话句占比（经验上 1/3 以上偏高，但**不得写成官方降档线**）；模板句自身有无语法错 |
| ② 高级词 | 巨微："越高级越好" | 何凯文/新东方："正确即可、地道优于难" | **以准确性为门槛**：用对给升级肯定；用错按错处理并提示"这个词你还没掌握，考场别用"，**绝不因词简单扣分** |
| ③ 长难句 | 巨微/潘赟/石雷鹏：倒装、虚拟是加分项 | 何凯文/新东方：简单句写对就行，勿堆砌 | 设"**可控复杂句**"标准：每段 1—2 处结构完整者加分；结构残缺的"伪长难句"必须按错误处理 |
| ④ 背整篇 vs 背功能句 | 王江涛/张剑：背整篇范文 | 石雷鹏/考虫：背功能句 | 按水平分流：句子写不对 → 建议整篇背 + 默写；句子对但组织乱 → 功能句 + 提纲训练。**搬运且咬合 = 可用；搬运不咬合 = 必须改** |
| ⑤ 内容深度权重 | 新东方：内容/逻辑为核心 | 何凯文：语言正确即可 | **分档差异化**：低档先救语言，不谈思想深度；中档要求分论点 + 例证落地；高档才要求角度不俗 |

## 4. 把方法论变成"批改动作"

| 方法论 | 批改时的具体动作 |
|---|---|
| 审题优先（共识 1） | 报告开头写"本题要求 N 个要点"，逐条打勾「提到 / 阐述 / 未提」；缺要点直接封顶档位 |
| 三段功能（共识 2） | 单独给"段落功能诊断"：每段首句是否点题、段间是否有逻辑关系 |
| 正确性优先（共识 3） | 先标【必须修改】硬错，再谈升级；硬错数量进入定档依据 |
| 词汇替换（共识 4） | 给"普通 → 进阶"替换，**附搭配/语域/可数性**，并给"没把握时的退路句" |
| 九宫格 / 功能句（潘赟、石雷鹏） | 用"首段三格 / 中段三格 / 尾段三格"诊断缺哪一格；缺格处给一句可填的句式 |
| 影响三维（海文） | 原因/影响段检查是否覆盖"个体 / 社会 / 发展"三个维度，缺维度就补一句 |
| 递进建议（海文） | 建议段检查是否只有"政府应该"一句，缺"个人 / 制度 / 长远"层次就提示补 |
| 拆句三步（田静、刘晓艳） | 长难句批改按"抓主干 → 理修饰 → 语义闭环"三步演示，并让用户复述 |
| 背—默写—仿写（王江涛） | 报告末尾给"重写任务"：只改 3 处，改完再提交对比；并建议默写本篇的高分句 |
| 去模板化（共识 6） | 识别 ≥3 处通用套话 → 给"去模板化改写"示例，说明它降档的真实机制（判"未有效阐述要点"） |

## 5. 分档差异化讲解策略（共识 5 的落地）

| 当前档位 | 优先讲什么 | 不必讲什么 |
|---|---|---|
| 第一/二档（1—8 / 4—6） | **先救语言**：主谓一致、时态、句子完整性；先能写出正确简单句 | 先不谈论证深度、不谈高级词 |
| 第三档（9—12 / 7—9） | 补要点 + 加例证 + 基础衔接；把 2—3 个句子升级成从句/非谓语 | 不要求"角度新颖" |
| 第四档（13—16 / 10—12） | 论证具体化（每点一句话解释+一个例子）、句式多样化、去空话 | 不要求生僻词 |
| 第五档（17—20 / 13—15） | 细节独特性、衔接的自然度、语言的地道度、逻辑的严密性 | 不再堆模板 |

## 6. 防伪提示（这些说法查不到官方依据，禁止写进评分准则）

- "模板占比超过 30% 直接降档""内容质量权重 30%""逻辑连贯性权重 20%""写作占全卷 20%"——均为营销/SEO 自造量化指标。
- "每少 10 词扣 1 分""每个语法错扣 0.5 分""3 处基础错误即降档"——无官方出处。
- "2026 年起六级评分新标准"——查不到任何官方文件。

**正确做法**：方向可以讲（模板重会拉低内容分、字数不足会酌情扣分），**比例与公式一律不写**；确需提及时标注"机构口径/阅卷经验"，并说明"官方未公布具体数值"。

## 7. 讲解语气（风格校准）

- **像阅卷老师一样给分，像辅导老师一样讲透**：先给档位与证据，再讲为什么。
- 不用"语感不好""多读多背"这类空话；每条建议必须**可执行、可检验**。
- 对基础一般的学生：语法术语首次出现加中文注释；每个【必须修改】给"同类错误自查方法"。
- 不承诺分数（不说"这样写能上 18 分"）；只说"在当前档位里，这几处改动最划算"。
- 每篇结束给 3 条以内"下次考试就能用"的动作，不给十条泛泛建议。

## 8. 六级（CET-6）写作的差异化要点

六级与考研的核心差别**不在"要不要模板"，而在论证密度**：150—200 词、2—3 个分论点且每个都要有支撑。

- **新东方四六级线**：总—分—总；六级开篇可放宽到 3 句；分论点必须"解释句 + 例子句 + 扣回句"（PEEL）；反模板；字数不足掉档。
- **石雷鹏/考虫线**：审题 → 框架 → 成文；"新颖高级表达的前提是用对"。
- **巨微线**：六功能段 + 大纲内高级词 + 倒装/虚拟当加分项（但强调语法先合格）。
- **六级特有风险**：议论性更强，纯"描述 + 升华"套路会让论证段显空；**模板句占比容忍度普遍被认为低于四级，但公开渠道没有任何官方量化口径**——批改时只能作为经验提示，不得写成规则。

**批改动作**：六级作文按 `rubric_cet6.md` 的 15 分五档批；重点查"分论点是否落地"（每段有没有解释与例证），语言层面优先消灭系统性语法错，其次做 2—3 处词汇升级。
