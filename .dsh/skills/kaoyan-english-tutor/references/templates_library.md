# 多文体高分模板库（骨架 + 槽位 + 示范句）

> **使用规则**
> 1. 模板只提供**骨架与功能句**，必须替换 `{ }` 槽位为本题的具体内容；整篇照抄 = 内容空洞，反而降档。
> 2. 每篇至少要有 **1 处"只有这道题才会出现"的细节**（图中具体物件、图表具体数字、题目具体情景）。
> 3. 一套"稳"（先保正确与结构），一套"进阶"（句式与论证更复杂）；**考试时先用稳的，确保写完再想进阶**。
> 4. 开头禁用 `With the development of science and technology`、`Every coin has two sides` 这类高频套话。
>
> 适用识别：题干是 `drawing` → 图画；`chart/table/graph` → 图表；`letter/email` → 书信；`notice` → 通知；`memo` → 备忘录。

## 三、多文体高分模板

> 说明：每套给「识别特征 → 骨架（每段功能）→ 槽位 → 首/主/尾示范句 → 破模板 3 条」。**槽位必须换**，示范句可直接背，但背的是句子不是段落。

### 3.1 英语一 图画作文 · 稳（描述 + 寓意 + 评论）

**识别特征**：Directions 出现 `drawing / picture / cartoon`，要求 describe → interpret → comment，160—200 词，20 分。

**骨架**
- P1（描述＋点寓意，3—4 句）：画面主体 → 细节动作 → 一句点破象征义。
- P2（析因，4—5 句）：两个原因（个体层面 + 社会层面）→ 一句后果/例证。
- P3（评论，3—4 句）：亮观点 → 一句对策 → 倒装/强调收尾。

**槽位**
```
P1: The drawing vividly portrays {人物}, who {动作}. Nearby, {细节}. Simple as it is, the picture
    conveys a thought-provoking message: {寓意}.
P2: Two factors may account for this. On the one hand, {原因1}. On the other hand, {原因2}.
    As a result, {后果}.
P3: In my view, {观点}. Only by {措施} can we {结果}.
```

**示范句**
```
The drawing vividly portrays a young man who keeps staring at his phone while crossing the road.
```
```
Two factors may account for this. On the one hand, smartphones offer instant rewards that make them hard to put down. On the other hand, many young people are under pressure to stay connected with friends and colleagues.
```
```
Only by learning to switch off from time to time can we truly enjoy the world around us.
```

**破模板 3 条**
1. 把 P1 的"画面＋寓意"改成"画面细节＋一句反问"（`Is this really the life we want?`），避免所有人同一句式开头。
2. P2 的原因必须**一个具体、一个抽象**（如"算法推荐"＋"从众心理"），不要两条都是"社会发展"。
3. P3 不要用 `In conclusion` 起头，换成 `If I were to sum up the picture in one word, it would be ...` 之类带个人判断的句式。

### 3.2 英语一 图画作文 · 进阶（对比 + 让步 + 升华）

**识别特征**：同上，适合基础较好、想冲 16+ 的考生；画面常有对比或反差。

**骨架**
- P1（对比式描述）：`While ..., ...` 两句对照 → 一句寓意。
- P2（让步 + 反驳，5 句）：承认合理面 → `Admittedly` 转折 → 指出根本问题 → 例证。
- P3（升华，3 句）：价值判断 → `It is ... that ...` 强调 → 呼吁。

**槽位**
```
P1: While {一方} {做法}, {另一方} {相反做法}. The contrast is striking, and it points to
    a simple truth: {寓意}.
P2: Admittedly, {合理面}. Yet this argument ignores {根本问题}. {例证/数据}. If left unchecked,
    {后果}.
P3: Ultimately, {价值判断}. It is {品质/行动}, rather than {表面因素}, that {结果}.
```

**示范句**
```
While some parents buy their children every gadget they ask for, others insist on making them earn what they want.
```
```
Admittedly, a comfortable childhood protects children from unnecessary stress. Yet this argument ignores the fact that easy access to everything weakens their ability to cope with failure.
```
```
Ultimately, what children need is not more things but more chances to try, fail and try again.
```

**破模板 3 条**
1. `Admittedly` 后必须真的让一步（写出对方最强理由），否则是假让步，阅卷老师一眼识破。
2. 例证用**具体可核实的现象**（某项调查、身边场景），不用 `for example, many people...` 这种零信息量句式。
3. 结尾避免"口号式升华"，把抽象价值落回一个可执行动作。

### 3.3 英语一 图表作文 · 稳（2024 起出现，描述数据 + 归因 + 结论）

**识别特征**：Directions 写 `chart / graph / table`，可能"图画＋图表"混合（2024）；20 分，160—200 词。

**骨架**
- P1（读图，3—4 句）：总体趋势一句 → 两个关键数据 → 一句概括。
- P2（归因，4—5 句）：主要原因一（经济/技术）→ 原因二（观念/政策）→ 一句影响。
- P3（结论，3 句）：趋势判断 → 建议/提醒。

**槽位**
```
P1: As the chart indicates, the proportion of {对象} rose from {数据1} to {数据2} over the period.
    Meanwhile, {另一对象} {变化}. Overall, the decade witnessed {总体判断}.
P2: Several factors may explain this shift. The most obvious one is {原因1}. In addition,
    {原因2}, which has made {结果} possible.
P3: If this trend continues, {预测}. It is therefore advisable that {建议}.
```

**示范句**
```
As the chart indicates, the proportion of households with internet access rose from 30% in 2010 to 78% in 2020.
```
```
Several factors may explain this shift. The most obvious one is the sharp drop in the cost of mobile data, which has made online services affordable for ordinary families.
```
```
If this trend continues, digital services will soon become the default rather than the exception.
```

**破模板 3 条**
1. 数据只挑**两个**，且必须"最大变化 + 反差最大"，不要逐个复述图表。
2. 描述数据用 `rise from A to B` / `stand at` / `account for`，避免全篇 `increase`。
3. 结论段不要重复 P1 的数据，改为"趋势含义 + 一句限定条件"（`provided that ...`）。

### 3.4 英语一 图表作文 · 进阶（数据反差 + 归因分层 + 限定结论）

**识别特征**：图表含两组以上数据或明显反差（2025 表格、2026 双图表）。

**骨架**
- P1：先给"最刺眼的反差" → 再给支撑数据 → 一句设问。
- P2：表层原因 → 深层原因（制度/文化）→ 一句"这解释了反差"。
- P3：有条件结论 + 提醒。

**槽位**
```
P1: The most striking feature of the table is the gap between {A} and {B}: {数据}. {补充数据}.
    Why should this be the case?
P2: At first glance, {表层原因}. A closer look, however, suggests that {深层原因}. This helps
    explain why {反差}.
P3: The trend is likely to continue, provided that {条件}. What matters is not {表象} but {实质}.
```

**示范句**
```
The most striking feature of the table is the gap between big cities and small towns: spending on education in the former is nearly three times that in the latter.
```
```
At first glance, the difference simply reflects income levels. A closer look, however, suggests that access to good schools matters even more than money.
```
```
The trend is likely to continue, provided that public resources are spread more evenly across regions.
```

**破模板 3 条**
1. 用"反差"而不是"增长"做主线，文章立刻有观点。
2. 深层原因要能解释**反差本身**，不能只是重复表层原因。
3. 结尾给"限定条件"，显示思维严密，这是 18+ 与 15 分的分水岭。

### 3.5 英语二 图表作文 · 稳（interpret + reasons + conclusion）

**识别特征**：英语二大作文 15 分，约 150 词，Directions 多为 `interpret the chart` + `give your comments / reasons`。

**骨架**
- P1（2—3 句）：一句总体趋势 + 一句关键数据。
- P2（3—4 句）：两个原因，一详一略。
- P3（2 句）：一句结论 + 一句建议/展望。

**槽位**
```
P1: The chart above shows the changes in {对象} from {年份} to {年份}. Overall, {总体趋势},
    with {数据} standing at {数值}.
P2: This trend can be attributed to two main factors. First, {原因1}. Second, {原因2}.
P3: In my view, {判断}. It is advisable that {建议}.
```

**示范句**
```
The chart above shows the changes in the number of online course users from 2015 to 2022. Overall, the figure climbed steadily, rising from 12 million to nearly 40 million.
```
```
This trend can be attributed to two main factors. First, high-speed internet has made online learning convenient and cheap. Second, working adults increasingly need to update their skills without leaving their jobs.
```
```
In my view, online education will remain a supplement rather than a substitute for classroom teaching.
```

**破模板 3 条**
1. 英语二词数只有 150 左右，P1 不要超过 3 句，否则 P2 论证被压缩。
2. 原因用 `First / Second` 可以，但两句句式要不同（一句名词性、一句从句），避免像清单。
3. 结论段必须给出**自己的判断**，不能只重复"这个趋势很好"。

### 3.6 英语二 图表作文 · 进阶（转折 + 双视角 + 建议）

**识别特征**：数据出现"总量升但结构变"或"城乡/群体差异"。

**骨架**
- P1：总量 + 结构反差（一句）。
- P2：`While ..., ...` 双视角解释。
- P3：`From my perspective` + 具体建议。

**槽位**
```
P1: {对象} has grown rapidly over the past decade, yet the growth has been uneven: {反差数据}.
P2: While {解释A}, it is also true that {解释B}. Together, these two forces have reshaped {对象}.
P3: From my perspective, {观点}. To make the most of this change, {建议}.
```

**示范句**
```
Online shopping has grown rapidly over the past decade, yet the growth has been uneven: while young consumers spend nearly half of their budget online, the figure for people over sixty remains below 15%.
```
```
While lower prices attract younger buyers, it is also true that older consumers value the chance to examine goods in person.
```
```
To make the most of this change, retailers should combine fast delivery with services that help older customers shop with confidence.
```

**破模板 3 条**
1. 用 `yet` 造转折，比 `however` 更紧凑，也更容易拿到"衔接"分。
2. 双视角必须都成立，不要写成"一方面好、另一方面坏"的空话。
3. 建议要具体到"谁做什么"，`The government should...` 太空。

### 3.7 英语一/二 书信 · 通用骨架（稳）

**识别特征**：Part A，约 100 词，10 分；`Write a letter to ...`，含 2—3 个要点。

> 9 类书信共用这两套骨架，差异体现在"专用句块"（3.8）。这样比背 18 套模板更抗模板痕迹。

**骨架（四块）**
1. 称呼（`Dear Professor Wang,` / `Dear Sir or Madam,`）
2. 第一句：说明写信目的（`I am writing to ...`）
3. 主体 2—3 句：按要点展开，一点一句，用 `First / In addition / As for` 衔接
4. 结尾 1—2 句：期待回复 + 落款（`Yours sincerely,` + 签名）

**槽位**
```
Dear {称呼},
I am writing to {目的：apply for / complain about / suggest / invite you to ...}.
{要点1}. {要点2}. {要点3}.
{期待语}.
Yours sincerely,
Li Ming
```

**示范句**
```
I am writing to suggest a few ways to improve the services of our university library.
```
```
It would be helpful if the library could extend its opening hours during the exam period.
```
```
I hope you will find these suggestions useful, and I would be glad to discuss them further.
```

**破模板 3 条**
1. 开头句必须出现**本题的具体对象**（图书馆、课程、活动名），不能只写 `I am writing to give you some suggestions`。
2. 主体段一点一句、句句不同主语，避免 `I think... I think... I think...`。
3. 结尾不要写 `I am looking forward to your reply` 就完事，加一句"我愿意配合"（`I would be happy to provide further details`）。

### 3.8 九类书信专用句块（配 3.7 骨架使用）

| 类型 | 开头句 | 主体句 | 结尾句 |
|---|---|---|---|
| 建议信 | `I am writing to offer a few suggestions on how to make better use of the university library.` | `It would be helpful if the library could extend its opening hours during the exam period.` | `I hope you will find these suggestions useful, and I would be glad to discuss them further.` |
| 感谢信 | `I am writing to express my sincere gratitude for the warm welcome you gave me during my stay in Beijing.` | `Your help with my research made my visit far more productive than I had expected.` | `Please accept my heartfelt thanks, and I hope I can return the favour some day.` |
| 道歉信 | `I am writing to apologize for missing our appointment last Friday.` | `An unexpected meeting at work kept me at the office until late in the evening, and I completely forgot to let you know.` | `I am truly sorry for any inconvenience this may have caused, and I would like to make it up to you by treating you to dinner this weekend.` |
| 申请信 | `I am writing to apply for the summer exchange programme offered by your university.` | `I believe my background in economics and my experience as a volunteer make me a suitable candidate for the programme.` | `I would be grateful if you could consider my application, and I am available for an interview at your convenience.` |
| 求职信 | `I am writing in response to your advertisement for a marketing assistant posted on your website.` | `During my two years as an intern at a local firm, I developed strong skills in data analysis and client communication.` | `I have enclosed my CV for your reference and would welcome the opportunity to discuss my qualifications in person.` |
| 投诉信 | `I am writing to complain about the poor quality of the laptop I purchased from your online store on 5 March.` | `Within a week of delivery, the screen began to flicker, and the battery now lasts less than two hours.` | `I would appreciate a full refund or a replacement, and I look forward to your reply within ten working days.` |
| 邀请信 | `I am writing to invite you to give a lecture on artificial intelligence at our university on 20 May.` | `The talk would last about ninety minutes and would be attended by around two hundred students.` | `Please let me know if the date suits you, and I will send you the detailed schedule.` |
| 推荐信 | `It is my pleasure to recommend Li Ming for the position of research assistant in your laboratory.` | `I have known him for three years, during which he has shown remarkable diligence and an unusual ability to work independently.` | `I recommend him without reservation and am confident that he will make a valuable contribution to your team.` |
| 咨询信 | `I am writing to inquire about the details of the English writing course advertised on your website.` | `I would like to know whether the course is open to non-English majors and how the classes are arranged.` | `Thank you for your time, and I look forward to hearing from you.` |

**书信进阶写法（破模板，通用 3 条）**
1. 用"背景一句 + 目的一句"开头：`Our library is a favourite place for students preparing for exams, yet it closes at nine. I am writing to suggest...`——比直接 `I am writing to` 更像真信。
2. 投诉信加"先肯定后投诉"（`I have always been a loyal customer, which is why I was disappointed to find...`），语气专业不撒气。
3. 求职/申请信把"我有什么"改成"我能为你做什么"：`I could help your team...`，录取率与分数都更高。

### 3.9 通知／告示（Notice）· 两套

**识别特征**：`Write a notice`，面向群体（学生/员工），须有标题、时间、地点、要求、联系方式；约 100 词。

**A. 稳（活动通知）**
```
NOTICE
{日期}

To {目的}, the {主办方} will organize {活动} on {日期} at {地点}.

The event will include {内容1} and {内容2}. All {对象} are welcome to attend.

Those who wish to take part are requested to sign up at {地点/方式} before {截止日期}.
For further information, please contact {联系人} at {电话/邮箱}.

{主办方}
```
示范：
```
A lecture on career planning will be held in the main hall at 7 p.m. on Friday, 12 June.
```
```
Those who wish to attend are requested to sign up at the Students' Union office before 10 June.
```
```
Please arrive ten minutes early, and bring a notebook if possible.
```
**破模板**：① 标题与正文之间空一行，别把 NOTICE 写进句子；② 用 `are requested to` 而非 `must`，通知语气礼貌；③ 至少给一个"到场要求"（提前入场/带证件），内容才完整。

**B. 进阶（招募/志愿者通知，带条件与回报）**
```
NOTICE

Volunteers are needed for the {活动} to be held on {日期}.

Applicants should be {条件1} and willing to {条件2}. Previous experience is welcome but not required.

In return, volunteers will receive {回报}. Please send your application to {邮箱} by {截止日期}.

{主办方}
```
示范：
```
Volunteers are needed for the international culture festival to be held on 18 October.
```
```
Applicants should be fluent in English and willing to work two evening shifts during the week.
```
```
In return, volunteers will receive a certificate and free access to all exhibitions.
```
**破模板**：① 把"欢迎报名"换成"我们需要什么样的人"，信息密度立刻上来；② 给一个"不要求"（`Previous experience is welcome but not required`），显得真实；③ 结尾必须有截止日期与投递方式，缺一项就丢格式分。

### 3.10 备忘录（Memo）· 两套

**识别特征**：`Write a memo to ...`，内部沟通，须有 To / From / Date / Subject 四行抬头；语言简洁、条目化。

**A. 稳（通知型）**
```
MEMORANDUM
To: All staff
From: {部门/姓名}
Date: {日期}
Subject: {事由}

This memo is to inform you that {事项}.

{具体安排：时间/地点/要求}.

If you have any questions, please contact {联系人} at {分机/邮箱}.
```
示范：
```
This memo is to inform all staff that the office will be closed for maintenance from 1 to 3 July.
```
```
During this period, please work from home and keep your phones available for urgent matters.
```
```
If you have any questions, please contact the administration office at extension 203.
```
**破模板**：① Subject 行用名词短语（`Office Closure, 1—3 July`），不要写成句子；② 正文第一句直接说事，不写 `I am writing this memo to...`；③ 用编号列安排，比整段更好读。

**B. 进阶（提议/汇报型）**
```
MEMORANDUM
To: {上级}
From: {姓名}
Date: {日期}
Subject: Proposal for {事项}

Purpose: This memo proposes {建议}.

Background: At present, {现状/问题}.

Proposal: I suggest that {具体做法1} and {具体做法2}.

Expected benefit: {收益}. I would welcome your comments before {日期}.
```
示范：
```
This memo proposes a trial of flexible working hours for the design team.
```
```
At present, most staff arrive within the same half hour, which causes long queues at the entrance.
```
```
I suggest that the team be allowed to start between 8 and 10 a.m. and that the trial last three months.
```
**破模板**：① 用 Purpose / Background / Proposal / Benefit 四个小标题，逻辑一目了然；② 建议句用 `I suggest that ... (should) ...`；③ 结尾给"征询意见的截止时间"，显示执行力。

### 3.11 六级议论文 · 通用骨架（稳）

**识别特征**：六级写作 15 分，150—200 词，`Directions: For this part, you are allowed 30 minutes to write an essay on ...`。

**骨架（三段）**
- P1（2—3 句）：现象/话题引入 → 一句概括观点。
- P2（4—5 句）：两个理由，一详一略，各配一句支撑。
- P3（2—3 句）：重申立场 → 一句建议/展望。

**槽位**
```
P1: In recent years, {现象} has become increasingly common. This trend has aroused heated
    discussion, and in my view, {观点}.
P2: Two reasons can be given for this. For one thing, {理由1}. For another, {理由2}.
P3: To sum up, {重申}. It is therefore advisable that {建议}.
```

**示范句**
```
In recent years, an increasing number of college students have taken up part-time jobs, a trend that has aroused heated discussion on campus.
```
```
For one thing, part-time work exposes students to real workplaces, where they learn to communicate with people of different ages. For another, earning their own money teaches them to plan a budget.
```
```
To sum up, part-time work is beneficial as long as it does not come at the expense of study.
```

**破模板 3 条**
1. P1 的"现象"必须带**具体范围或数据感**（`on campus` / `in big cities`），不要写 `With the development of society`。
2. P2 两个理由要**分属不同层面**（个人/社会、短期/长期），否则是同一理由说两遍。
3. P3 用 `as long as` / `provided that` 加限定，立场更成熟。

### 3.12 六级议论文 · 进阶（让步 + 反证 + 收束）

**骨架**
- P1：争议引入 + 我的立场（一句）。
- P2：让步（对方最强理由）→ 转折 → 反证/例证。
- P3：条件式结论。

**槽位**
```
P1: Few issues are more hotly debated than {话题}. While some insist that {对立观点},
    I would argue that {我的观点}.
P2: Admittedly, {对方合理处}. This argument, however, overlooks {被忽略的事实}. {例证}.
P3: The real question is not whether {A}, but how {B}. {条件句结论}.
```

**示范句**
```
Few issues are more hotly debated than whether students should bring mobile phones into the classroom.
```
```
Admittedly, a phone can be a useful dictionary or a quick way to check facts. This argument, however, overlooks how easily a notification pulls attention away from the lesson.
```
```
The real question is not whether phones should be banned, but how their use can be kept within sensible limits.
```

**破模板 3 条**
1. `Admittedly` 后面必须写出对方**最强**的理由，弱理由让步等于没让。
2. P3 的 `not whether ... but how ...` 是高频高分句式，但一篇只能用一次。
3. 例证要能"反证"：写一个因手机分心而成绩下滑的具体场景，比空谈有效。

### 3.13 六级四种题型的适配（配 3.11 / 3.12 骨架）

| 题型 | 识别特征 | 首段定式 | 主体推进 | 尾段定式 |
|---|---|---|---|---|
| 现象解释型 | 题干给一个社会现象，问原因/看法 | `In recent years, ... has become increasingly common.` | 原因一（个体）→ 原因二（社会）→ 一句影响 | `In my view, ... as long as ...` |
| 正反观点型 | 题干出现 `Some people think... Others believe...` | `When it comes to whether ..., opinions vary widely.` | 正方最强理由 → 反方最强理由 → 我的取舍 | `Weighing the two sides, I believe that ...` |
| 名言警句型 | 题干引一句谚语/名言 | `"..." This well-known saying reminds us that ...` | 释义 → 例证（历史/身边）→ 反面假设 | `In a word, ... it is ... that ...` |
| 图表型 | 题干附 chart/table | `The chart above illustrates the changes in ...` | 一句数据 + 两个原因 | `If this trend continues, ...` |

**各型示范句**
```
When it comes to whether students should be allowed to bring mobile phones into the classroom, opinions vary widely.
```
```
"Where there is a will, there is a way." This well-known saying reminds us that determination is often the first step towards success.
```
```
The chart above illustrates the changes in the number of private cars in a medium-sized city over the past ten years.
```

**破模板 3 条**
1. 名言警句型**不要**把名言再翻译一遍当第二段，直接进入"这句话对在哪、漏在哪"。
2. 正反观点型必须真的给出取舍，`Both have merits` 是最常见的低分结尾。
3. 图表型六级只写 150—200 词，数据最多两句，重心放原因。

### 3.14 六级书信／应用文 · 两套

**A. 稳（建议/感谢/邀请通用）**
```
Dear {称呼},

I am writing to {目的}. {背景一句}.

First, {要点1}. Second, {要点2}.

{期待语}. I look forward to hearing from you.

Yours sincerely,
Li Ming
```
示范：
```
I am writing to suggest some changes to the English corner that would make it more attractive to first-year students.
```
```
First, the topics could be announced a week in advance so that participants have time to prepare.
```
```
I would be happy to help organize the first session if that would be useful.
```
**破模板**：① 称呼后用逗号（美式）或冒号，全文统一；② 主体两点即可，六级 150 词不必凑三点；③ 结尾加一句"我能做什么"，比空泛期待更有诚意。

**B. 进阶（投诉/申请，带背景与诉求）**
```
Dear {称呼},

I am writing to {投诉/申请} regarding {具体对象}. {背景一句，说明关系}.

{问题或资历1}. {问题或资历2}.

I would appreciate it if you could {诉求}. I am available at {联系方式} if you need further details.

Yours sincerely,
Li Ming
```
示范：
```
I am writing to complain about the delay in delivering my order, which was placed on 3 April.
```
```
According to your website, the parcel should have arrived within five working days, yet it is now two weeks late.
```
```
I would appreciate it if you could either send a replacement or refund the full amount.
```
**破模板**：① 用 `which` 从句补充订单号/时间，信息具体；② 诉求只提一个（换货或退款），不要既要求赔偿又要求道歉；③ 结尾留联系方式，符合真实商务信函。

### 3.15 六级翻译 · 段落组织两套

**识别特征**：整段汉译英，140—160 词，5—8 句；文化、社会、经济、科技类话题为主。

**A. 稳（顺译 + 逐句立主干）**
- 步骤：① 断句（按意群切 5—7 句）→ ② 每句先定主谓宾 → ③ 修饰成分用从句/分词挂后 → ④ 逻辑词串联（`First / Moreover / As a result / In short`）。
- 骨架：`总起一句 + 分述三句（每句一个事实）+ 收束一句`。
- 示范：
```
China has a long history of tea culture, which dates back more than two thousand years.
```
```
Today, tea is not only a daily drink but also an important part of social life.
```
```
In short, a cup of tea often carries more meaning than the drink itself.
```
**破模板**：① 一句一个事实，不要把三个短句硬塞进一个长句；② 逻辑词只用 2—3 个，多了反而像模板；③ 遇到不会的词用上位词替换（`茶具` → `tea sets`，不要生造词）。

**B. 进阶（重组 + 合并 + 语序调整）**
- 步骤：① 找全文"主句"（通常是最后一句结论）→ ② 把背景信息压成分词短语/同位语置前 → ③ 短句合并（which / 同位语 / 插入语）→ ④ 名词化提升密度。
- 骨架：`背景（分词/同位语）+ 主句 + which 补充 + 结论`。
- 示范：
```
With a history of more than five thousand years, China is home to a wide variety of traditional festivals.
```
```
The Spring Festival, the most important of them all, brings families together no matter how far apart they live.
```
```
It is this shared experience, rather than any single custom, that keeps the festival alive.
```
**破模板**：① 合并短句时先确认逻辑关系（因果/并列/补充），关系不清就不要硬合；② 名词化别过头，`the improvement of the living standard of the people` 不如 `better living standards`；③ 每段最多一个 `it is ... that ...` 强调句。

### 3.16 六级翻译 · 八个高分句式（可直接嵌入 3.15）

```
1. 定语从句：The policy, which was introduced in 2010, has benefited millions of rural families.
2. 分词状语：Faced with fierce competition, many small firms have turned to online sales.
3. 名词化：The rapid growth of the service sector has created millions of jobs.
4. 形式主语：It is estimated that nearly half of the population now shops online.
5. 被动转主动：People generally believe that ...（比 It is widely believed 更自然，二者皆可）
6. 比较结构：The more developed a city is, the more attractive it is to young people.
7. 让步：However difficult the task may be, it is worth trying.
8. 同位语：Beijing, the capital of China, is both an ancient city and a modern metropolis.
```

**使用纪律**：一段译文用 3—4 个即可；第 4、5 条属"评价性插入"，只适合段末；第 6、7 条容易写错，务必先保证主谓一致。
