0下载与解压

  1. 打开仓库页面：github.com/ZhikHuang/kaoyan_English_essay_tutor
  2. 点绿色的 Code 按钮 → Download ZIP（见下图 ①）
  3. 解压到「有空间、不在同步盘里」的目录，例如 D:\kaoyan-english-writing
  4. 检查解压结果：文件夹里应同时看到 app\、skill\、tools\、一键批改.cmd
解压位置三不要：不要放 C:\Program Files\（需要管理员权限，写补丁会被拒）； 不要放 OneDrive / 坚果云等同步目录（会锁文件、回滚版本）；不要直接在压缩包里双击运行（只读临时目录，写不进数据）。 正确做法：先解压到普通磁盘目录，再双击里面的文件。

1打开练习台，认识主界面

双击 app\index.html（建议用 Edge 或 Chrome）。打开后第一眼看到的就是「总览」页（图 2）。

看到「数据已加载 · 补丁 N 个」就说明一切正常。 如果显示「⚠ 未能读取 data/state.js」，检查 index.html 与 data\ 是否在同一层（app\ 目录被移动过就会这样）。

2选一道题

点顶部「题库」。题库支持三级筛选：科目（英语一 / 英语二）→ 类别（考研真题 / 模拟题 / 我的题目）→ 题型（大作文 / 小作文 / 翻译 / 长难句）。

点开一道题，看题干 + 示意图 + 练习轨迹

点任意题目条目即可展开（图 4）。真题的图画/图表都是本站自绘的 SVG 示意图，不是原卷图片，用于说明画面内容。

新题怎么办：手里有真题之外的自命题？去「提交作文」页最下方的「上传自己的题目」， 把题目原文和作文一起贴进去。AI 会先判断是否和题库里的题重复：重复就归并到那道题下（练习次数 +1）， 确实是新题才归档到「我的题目」类别。

3写作文并提交

点顶部「提交作文」，按图 5 从上到下填完即可。

区域怎么填
1. 选题目下拉按科目分组（英语一 / 英语二），已练过的题会标 [练过 N 次]。选错题会导致批改口径全错，务必先确认。
2. 作文正文直接粘贴英文原文。手写稿可以跳过正文，用「3. 手写照片」交同一次作文的另一种形式（照片会导出到 data\uploads\，你在对话里告诉我路径即可转录）。
3. 附加要求可选。例如「重点看时态」「讲细一点」「这是六级作文」。
4. 与上一篇的关系这是同一篇作文的修改稿时，选上一稿，之后可以并排对比「哪些问题改好了」。
5. 提交点「提交，等待 AI 批改」。右侧会显示即将分配的编号（如 sub_0003）。
6. 提交之后记住这句指令：批改待批改作文。下面 §4 讲怎么把它交给 AI。
提交 ≠ AI 已经看到。网页没有联网权限，提交只写进浏览器本地存储（localStorage）。 必须走 §4 的任意一种方式，AI 才能读到；否则 AI 会回你「没有待批改的作文」。

4让 AI 批改（三种方式，任选一种）

方式怎么做适合
A. 网页按钮双击 start-helper.cmd → 回到网页「提交作文」页最下方 → 点「一键批改（N 篇）」连着练好几篇，最省事
B. 一键批改.cmd双击仓库根目录的 一键批改.cmd，等窗口跑完（1—5 分钟）不想开常驻服务
C. 直接在对话里说对 AI 说：批改待批改作文想顺手追问细节

方式 A 的界面长这样（推荐）

为什么方式 A 最稳：点「一键批改」时，网页会先把本机提交同步成 app\data\pending_submissions.json，AI 与批改服务都读这份文件，所以不会再出现「AI 说没有待批改作文」。
如果按钮是灰的（「暂无待批改」）：说明这篇已经批过了（app\data\patches\ 里有对应补丁）， 或者你还没提交。想重批同一篇：把补丁文件删掉再点一次（或直接对 AI 说「重批 sub_0003」）。

5看批改结果

批改完成后，点顶部「批改结果」查看（图 7）。

逐句批改与「翻译采分点」

一份批改报告有哪六块

板块你要做什么
1. 整体评价与评分看档位 + 分数 + 一句话依据。分数只是参考，档位说明才是重点。
2. 逐句批改优先处理【必须修改】：每条都会写「错在哪 → 为什么错（语法规则）→ 怎么改 → 同类自查」。
3. 修改后全文朗读一遍，感受「同样的意思，怎么写得更好」；加粗处就是改动点。
4. 词汇升级 3—5 处每处都给「没把握时的退路句」，用不熟就别用。
5. 语法升级 1—2 处给出公式 + 为什么这里适合 + 写错的风险点。
6. 本篇注意事项 + 模板建议3 条以内的可执行动作；需要模板时会给骨架与「去模板化」改法。

6复盘与提分

① 错题与语言点库：把错误按语法类别归档

点顶部「错题与语言点库」。AI 每次标出的【必须修改】都会自动归类（主谓一致、时态、冠词、从句、搭配……），并累计出现次数。

用法：做完 3—5 篇后回来看这里。如果「主谓一致」出现 6 次、「冠词」出现 4 次， 下一篇动笔前先默念这两条，写完专门检查这两项——这比重复刷题有效得多。

② 分数趋势：只看趋势，不纠结单次分数

③ 改稿对比：同一篇作文的第 1 稿 vs 第 2 稿

提交时选「是某一篇的修改稿」，之后在批改结果或题库里点「总览对比」，就能把每稿的作文、得分、【必须修改】清单并排看，并自动标出「上一稿的问题是否已解决」。

复盘三步法（建议固定下来）：① 先改完这一篇【必须修改】；② 把 2—3 个升级句抄到自己的句本上并默写； ③ 三天后回看错题库里出现最多的那一类，写一段 3 句的小练习专攻它。

7更新题库（每年 12 月做一次）

每年考研结束后（12 月底），回到「题库」页顶部的「一键更新题库」面板（图 11）。它会检查两个科目的年份覆盖，缺哪年补哪年。

  1. 先开服务：双击 start-helper.cmd（窗口保持开着）
  2. 回到网页点「重新询问」：面板会显示当前覆盖与缺口
  3. 点「一键更新题库」：AI 联网核对多个来源、补齐两科真题，写完自动备份
  4. 看结果：网页自动重载；如需回退，面板下方有「回退到更新前的备份」
更新后建议跑一次自检：node app\tools\validate.js。 它会检查两科年份完整性、每道题的字段、英语二翻译是否有英文原文。

8常见问题

现象原因与处理
AI 说「没有待批改的作文」提交只在浏览器本地。先双击 start-helper.cmd，回网页点一次「一键批改」（会自动同步成 app\data\pending_submissions.json）；或点「导出本机提交 JSON」另存为该文件；或把作文直接粘进对话。
双击 一键批改.cmd 报「找不到 node」本机没装 Node.js。脚本会自动尝试 DSH 自带运行时；仍失败就装 Node.js 18+，或直接在对话里说「批改待批改作文」。
双击脚本满屏「不是内部或外部命令」脚本行尾被改成 LF 了（常见于手工另存）。从 GitHub 重新下载即可，仓库已用 .gitattributes 强制 .cmd 用 CRLF。
题库显示 0 道题多半是 questions.js 引用了不存在的图函数。跑 node app\tools\validate.js 看报错，或点「回退到更新前的备份」。
提交后看不到结果确认 app\data\patches\ 下有 sub_XXXX.js（必须是 .js）；再点右上角「重新加载数据」。
网页按钮点不动 / 一直「正在检测」start-helper.cmd 的窗口被关了。重新双击它，再点「重新检测服务」。
顶栏提示「未能读取 data/state.js」index.html 被单独移走了。确保 app\ 整个目录一起移动。
清除缓存后提交没了「清除本机草稿与图片缓存」会删掉全部本机提交。清之前先「导出本机提交 JSON」备份。
想换端口node app\tools\grade-helper.js --port 8899，同时改 app\index.html 里的 HELPER_URL。
分数和我预期差很多评分是模拟评分（民间整理的官方档位口径），不是真实阅卷。看档位理由是否成立，比看分数有用。
一条命令体检：在项目根目录运行 node app\tools\validate.js --report（数据 + 页面渲染仿真）， 再运行 node tools\check-repo.js（路径/命令/技能包结构）。两项都通过，说明这套工具是健康的。

9数据、备份与隐私

数据位置要备份吗
你的提交（作文正文）浏览器 localStorage（kaoyan_subs_v1）要（导出 JSON）
批改结果app\data\patches\sub_XXXX.js要
同步给 AI 的提交app\data\pending_submissions.json自动生成
手写照片app\data\uploads\要
考试日期 / 称呼app\data\state.js 的 meta可选
题库app\data\questions.js（由生成器产出）随仓库
备份只需两步：① 网页「错题与语言点库 → 导出本机提交 JSON」；② 把整个文件夹复制一份 （app\data\ 里就包含了补丁、照片、题库）。换电脑时把文件夹拷过去即可，全部使用相对路径。
隐私：网页零外链、零请求，断网照常用；所有数据都在你自己的文件夹里。 只有「一键更新题库」会联网检索公开资料，且只在你点击时发生。

附录 C · 批改标准从哪来

分档描述参照教育部教育考试院历年《考试大纲》的表述（经多方逐字一致转引），档内微调与扣分公式属阅卷口径， 官方未公布逐条细则；批改时会明确标注「模拟评分」。词汇/语法升级与模板库整合自公开的名师与机构方法论 （王江涛、朱伟、潘赟、石雷鹏、刘晓艳、唐迟、何凯文等），只吸收可执行的方法，不复制讲义。 详细依据见 skill\references\rubric_kaoyan.md、rubric_cet6.md、master_methods.md。
