1一分钟看懂：这套东西是什么

一句话：网页负责写和看，DSH 里的 AI 负责批改，两边靠本地文件自动同步。 你写作文、选题目、翻看历史批改都在网页里完成；批改由 AI 按对应科目（英语一 / 英语二）的评分标准逐句完成，结果自动回到网页，不需要你复制粘贴。

→
② 选题目题库 95 道任选（英语一 / 英语二分科筛选）
→
③ 提交作文粘贴正文，点提交
→
④ 触发批改点按钮 / 双击脚本 / 说一句话
→
⑤ 看批改与复盘注意事项·错题库·趋势

3完整使用流程：一次练习的 8 步

建议第一次严格按这个顺序走一遍，之后可以只留第 1、3、5、6、8 步。

  1. 双击 index.html，浏览器打开练习台。默认在「总览」页，能看到累计提交、已批改、平均得分率。
  2. 选题目：点上方「题库」标签 → 用「考研真题 / 模拟题 / 我的题目」筛选 → 找到想练的那道题 → 点开看题干、示意图与练习轨迹。
  3. 进入写作：在题目里点「用这道题写一篇 →」，页面跳到「提交作文」并自动选中该题。
  4. 写作文：按题干要求写（建议先写在纸上，更贴近考场），写完整理成文字。
  5. 粘贴并提交：在「2. 粘贴我的作文正文」里粘贴 → 按需填写第 3 至 6 项（见第 4 节）→ 点「提交，等待 AI 批改」。此时网页顶部「提交作文」上会出现红色数字角标（待批改篇数）。
  6. 触发批改，三种方式任选其一（见 3.2）。
  7. 看批改：回网页点「批改结果」标签，展开那一条，按顺序读：整体评价 → 逐句批改 → 修改后全文 → 表达积累 → 本篇注意事项。
  8. 复盘：写完一篇后，固定去三处看一眼 —— 「错题与语言点库」看同类错误有没有反复出现、「分数趋势」看最近三次有没有在涨、「题库」看哪些题还没练。下次动笔前，先读一遍上次的注意事项。

4提交作文页面的 6 个分点怎么填

先纠正一个常见误解：这 6 项不是 6 种上传方式，而是同一次提交的 6 个步骤。 填完点一次「提交」，就生成一条待批改记录。同一道题想练第二遍，就再走一遍这 6 项、再提交一次 —— 编号自动递增，练习次数 +1，全部挂在那道题下面。
分点名称作用是否必填
1选择题目决定这次练的是哪道题。下拉按三类分组（考研真题 / 模拟题 / 我的题目），并标注[练过 N 次]或[未练习]。下方会实时显示该题的题干、示意图和练习轨迹。必选
2粘贴我的作文正文作文正文本身，直接粘贴英文。这是最主要的输入。与第 3 项至少填一个
3手写照片同一篇作文的照片形式（二选一即可，不必同时填）。选好照片后点「保存到 data/uploads/」，页面会帮你起好文件名。可选
4图片相对路径照片存放位置（如 data/uploads/sub_0003.jpg）。第 3 步选完照片后会自动填好，也可以手填。选照片时自动
5附加要求对这一次批改的额外要求，例如「重点看时态」「讲解要更细」「只批语言不改结构」。可选
6与这道题的关系独立一篇（另起一次练习）或 是某一篇的修改稿（挑上一次那一篇）。选后者才能形成「改稿链」，之后可以并排对比（见第 7 节）。想对比改稿就选后者

常见疑问

同一道题练第二遍，会不会覆盖上一次？

不会。每次都新建一条记录（sub_0003、sub_0004…），题库里那道题的「练习与改稿记录」会按时间列出全部提交与得分。

能不能一次交两篇不同的作文？

不能，一次提交只对应一篇作文。要交两篇就提交两次，或者选两道不同的题分别提交。

提交后想改一下再交，怎么办？

直接再提交一次即可，并在第 6 项选「是某一篇的修改稿」。这样两稿就会并排出现在「改稿总览」里。

草稿会不会丢？

不会。页面里的草稿与提交记录都保存在本机浏览器里（localStorage），关掉再打开还在。但清除浏览器数据会丢未批改的草稿，已批改的结果在 data/patches/ 里不受影响。

5三种提交方式：题库选题 / 上传自己的题目 / 直接对话

方式一：从题库选题（最常用）

  1. 「题库」→ 筛选「考研真题」（2010—2026，共 34 道）或「模拟题」（10 道）。
  2. 点开题目，核对题干与示意图（真题的图画/图表是本站自绘示意图，非真题原图）。
  3. 点「用这道题写一篇 →」，粘贴作文，提交。

方式二：上传自己的题目（题目 + 作文一起交）

在「提交作文」页最下方有独立的「上传自己的题目」板块。适用于：你手上有别处的题目（讲义、真题本、老师给的题）。

  1. 粘贴题目原文（中文题干、英文 Directions、图画文字说明，有多少贴多少）。粘贴过程中页面会实时提示相似题目（显示相似度百分比）。
  2. 选择处理方式：
    • 「这是一道新题」→ 归档到「我的题目」类别，编号 q_mine_001 起递增；
    • 「和题库里已有的题重复」→ 选择目标题目，你的作文与批改结果会归并到那道题下面（练习次数 +1，不会重复建题）。
  3. 粘贴作文正文，点「提交题目与作文」。
判重是双保险：页面侧用相似度给出提示与「就是这一道 → 归并」按钮；AI 侧批改时还会再判一次 —— 明显是同一道题就自动归并，拿不准会先问你。如果你已经提交了才发现忘了标，直接在对话里说「sub_0007 其实是 sub_0005 的修改稿」即可补上关联。

方式三：直接在 DSH 对话里交（最快）

不用先写网页，把题目和作文直接粘给 AI，说「批改这篇作文」。批改结果同样会写成补丁回到网页。

三种方式的关系：方式一、二在网页里留下完整记录（练习次数、改稿链、错题库都靠它统计）；方式三最省事，但网页里的「新提交」只存在浏览器本地，AI 读不到文件 —— 所以方式三请直接粘贴作文，或在网页点「错题与语言点库 → 导出本机提交 JSON」另存到 data/ 后再告诉 AI。

6.1 一条批改记录里各部分的读法

  1. 分数与档位：例如 13 / 20（13-16 分档，较好完成任务）。旁边有原文词数与改后词数，用于对照 160—200 词要求。
  2. 分项评价：内容与审题 / 语言准确性与丰富性 / 结构与衔接 三个维度，每个维度都引用你原文的具体句子作为依据。
  3. 逐句批改：核心部分。每条包含：
    • 必须修改 影响语法正确性或妨碍理解的问题 —— 这类必须逐条改；
    • 可选优化 正确但可以更地道的表达 —— 有余力再改；
    • 可保留 写对了的句子，说明"为什么可以保留"。
    每个【必须修改】都按「错在哪 → 为什么错（点名语法规则）→ 怎么改 → 同类错误如何自查」四步讲解。
  4. 修改后全文：保留你的原意与正确句式，只改该改的地方，加粗处即主要修改。可以对照着看"我的文章升级后是什么样"。
  5. 表达积累：3—5 个考场可直接复现的表达，附中文意思与适用场景（不堆砌生僻词）。
  6. 本篇注意事项：从本篇错误里提炼的最该优先改的几条 —— 下次动笔前先看这里。

6.2 三色错误高亮怎么用

红色
必须修改
鼠标悬停可看问题与改法
黄色
可选优化

绿色

每条作文上方有「关闭/开启错误高亮」按钮：第一遍建议开着看（对照批改），第二遍建议关掉再自己找一遍错，效果最好。

7同一篇作文改了又改：改稿链与并排对比

7.1 要做的操作（每次改稿 2 次点击）

  1. 填好作文后，看第 6 项「这一篇和这道题的关系」。
  2. 选「是下面某一篇的修改稿」，挑上一次那一篇 → 提交。网页会自动记下稿次关系，把几稿连成一条「改稿链」。

7.2 两个查看入口（都只需一次点击）

入口位置能看到什么
总览对比 「批改结果」页顶部；或题库里那道题的「练习与改稿记录」面板 → 点「总览对比（N 稿）」 每一稿并排一列：那一稿的作文原文、得分、字数、【必须修改】逐条清单、复盘重点、修改后全文，以及一行高亮的 「与上一稿相比：已解决 X / N 项，仍然存在……」；顶部还有一句分数进步总结（如 13/20 → 16/20（得分率 65% → 80%，提升 15%））
练习与改稿记录 题库 → 点开那道题 该题全部提交的时间线表格，标出「第 1 稿 / 第 2 稿 / 独立一篇」，每行都有「看批改」「对比」两个按钮

对比视图里每一稿还带两个按钮：看完整批改（跳到那一稿的全部批改内容）、基于本稿改一版（把那一稿填回提交页，你改完直接提交就自动成为下一稿）。

同一篇作文改到第三稿即可，再多收益递减。更值得做的是换一道新题检验：把上一题总结的问题带到新题里，看还会不会犯 —— 这才是错题库真正的用法。

8手写作文怎么办

考场上是要手写的，所以平时尽量手写。手写稿交给 AI 有两条路：

路线 A：网页登记（推荐，记录完整）

  1. 拍照：把作文拍清楚，光线均匀、四角完整、字迹可辨。
  2. 在「提交作文」页第 3 项点「选择照片」，页面会显示预览，并按即将分配的编号自动起好文件名（如 data/uploads/sub_0003.jpg）。
  3. 点「保存到 data/uploads/」，在弹出的保存对话框里选到本文件夹的 data\uploads\ 目录即可。第 4 项的路径会自动填好。
  4. 提交，然后触发批改。AI 会先准确转录你的手写内容（保留你原有的拼写与语法错误，不会偷偷改对），再逐句批改。

路线 B：直接在对话里发照片（最省事）

把照片拖进 DSH 对话框，说「批改这篇作文，这是 20XX 年真题的大作文」。AI 转录后批改，结果同样回到网页。

辨认不清时会发生什么：AI 会把无法确认的地方列出来问你，而不会猜着写、更不会把识别错误当你的错误。若整篇照片模糊，会要求你重拍，而不是给 0 分。
照片规范建议：①横平竖直、不要斜拍；②单页一张，别把两页挤进一张；③不要用美颜/滤镜（会糊掉字母）；④文件名保持简单（如 sub_0003.jpg），避免空格与特殊字符。

9.2 ⚠ 题型已变化（做题与批改都要注意）

年份大作文题型例子
2010—2023图画作文
based on the following drawing		文化火锅、手机时代的聚会、相携、途中、图书馆、美猴王父子对话、龙舟赛……

英语二的情况不同：17 届（2010—2026）大作文全是图表作文——柱状图、饼图、表格、折线图逐年轮换 （2012 表格、2015/2016/2018/2020 饼图、2017/2023 折线图、其余多为柱状图），分值 15 分、约 150 词， Directions 为 interpret the chart + give your comments。因此英语二的核心是描述数据的能力： 说清趋势与占比、挑关键数字、别逐行抄表。翻译也与其他题型不同，是整段英译汉 15 分。
做题时务必看清题干结尾是 based on the following drawing 还是 based on the following chart(s)。 图表作文必须写数据趋势并分析原因，只写画面或不引用数据都会失分。批改也会按对应标准执行（技能里已有专门的图表作文检查清单）。

10.4 使用建议（把它用出效果）

  1. 先练真题，再练模拟题。真题是标尺，模拟题是加练。2010—2026 的大小作文足够覆盖所有常见题型。
  2. 每周固定节奏：3 篇大作文 + 3 篇小作文 + 2 次翻译练习；每篇都走完"提交 → 批改 → 读注意事项 → 隔天重写一稿"。
  3. 错题库每周清一次。同一类别连续出现三次以上，就停止刷新题，专门做这个类别的针对性练习（注意事项里都给了具体动作）。
  4. 手写练手感。考前两个月起尽量手写、限时（大作文 35 分钟、小作文 15 分钟），再拍照交给 AI 批改。
  5. 不要把"修改后全文"当范文背。它的作用是让你看清"自己的文章能变成什么样"，真正要记的是【必须修改】的原因和自查方法。
  6. 注意题型变化。2024 起已出现图表作文，2025 是表格、2026 是双图表 —— 数据描述与原因分析必须专门练。

11.2 一键更新题库（每年 12 月考研结束后做一次）

这是为下一年考生准备的功能：网页里点一个按钮，AI 自己联网查最新真题并补进题库。位置在「题库」页顶部的「一键更新题库」面板。

  1. 先启动服务：start-helper.cmd（Windows）或 ./start-helper.sh（macOS）。
  2. 点「一键更新题库」：面板会显示当前覆盖年份与缺失年份，例如 题库覆盖 2010—2026（17 个年份）。缺年份时按钮直接写明「补 2027」。
  3. 等它跑完：AI 会联网交叉核对多个来源，按题库格式追加题目。更新前会自动备份 app/data/questions.js 到 app/data/backups/。通常几分钟。
  4. 自动刷新：网页检测到题库变化后自动重新加载；也可点「重新加载数据」。
  5. 出问题就回退：面板上的「回退到更新前的备份」一键恢复。
也可以不用网页按钮：终端执行 node tools/grade-once.js --update 2027（macOS 可 ./update-bank.sh 2027）， 或直接在智能体会话里说「联网更新考研英语一和英语二题库，补齐 2027 年真题」。
为什么需要联网：最新真题的题目细节（图画内容、图表数据、书信原文）只有公开来源才有，AI 必须联网查证并交叉核对； 查不到的细节它会如实标注「不确定」，不会编造。更新完成后建议跑一次 node app/tools/validate.js 确认题库结构完好。

11.3 在其他智能体里使用（Codex / Cursor / Claude Code 等）

网页、题库、批改结果都是普通文件，任何能读写本地文件的智能体都能接手。区别只在「评分标准放在哪」：

智能体怎么让它读到评分标准
DSH运行 node install.js 会自动装到 ~/.dsh/skills/kaoyan-english-tutor/，任何会话都能用
